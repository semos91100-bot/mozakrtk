تشغيل مُذاكرة على Vercel

1) ارفع المشروع على GitHub ثم اعمله Import في Vercel.
2) افتح Supabase وأنشئ مشروعًا جديدًا.
3) من SQL Editor شغّل محتوى الملف supabase.sql.
4) من Supabase > Settings > API انسخ:
   - Project URL
   - service_role key
5) في Vercel > Project > Settings > Environment Variables أضف:
   SUPABASE_URL = رابط المشروع
   SUPABASE_SERVICE_ROLE_KEY = service_role key
   JWT_SECRET = أي نص عشوائي طويل (مثلاً 32+ حرف)
   ADMIN_EMAIL = semos91100@gmail.com
   ADMIN_PASSWORD_HASH = القيمة الموجودة في .env.example
   GEMINI_API_KEY = مفتاح Gemini (اختياري، فقط لو عايز مدرس AI)
   GEMINI_MODEL = gemini-2.0-flash
6) اعمل Redeploy.

بيانات الأدمن في النسخة دي ليست داخل JavaScript أو ملف PHP عام؛ البريد والهاش يقرآن من Environment Variables في Vercel.

مهم: Vercel لا يشغّل PHP هنا، ولا يمكن الاعتماد على ملفات JSON داخل api/storage كقاعدة بيانات دائمة. لذلك النسخة تستخدم Supabase كقاعدة بيانات دائمة.
