نسخة Vercel الكاملة — نظام دعم فني احترافي + ألوان جديدة
=============================================================

1) فك الضغط وارفع كل المحتويات (بما فيها فولدر assets) إلى GitHub.
2) في Vercel اختر المستودع واضغط Deploy.
3) لا تحتاج PHP أو Node أو Build Command أو Environment Variables.

الجديد
------
- صفحة "الدعم الفني" بقت نظام تذاكر كامل (Ticketing System): تصنيف، أولوية،
  حالة، ثريد ردود، إشعارات، ولوحة أدمن منفصلة لإدارة كل التذاكر.
- هوية ألوان جديدة احترافية (أزرق + ذهبي) في assets/styles.css مع وضع ليلي كامل.
