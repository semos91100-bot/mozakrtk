طريقة تشغيل النسخة المشتركة على Vercel
========================================

النسخة دي تحل مشكلة إن كل جهاز كان بيخزن التذاكر والإشعارات لوحده.
لازم تربطها بقاعدة Supabase مرة واحدة، وبعدها البيانات تصبح مشتركة بين كل الأجهزة.

1) أنشئ مشروع Supabase.
2) افتح SQL Editor وشغّل الملف SUPABASE.sql الموجود في نفس المشروع.
3) من Settings > API انسخ:
   - Project URL
   - service_role key
4) في Vercel > Settings > Environment Variables أضف:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
   SESSION_SECRET

اختياري:
   ADMIN_EMAIL = semos91100@gmail.com
   ADMIN_PASSWORD = alton112233

5) اعمل Redeploy.

بعد الربط:
- الطالب يقدر يفتح تذكرة من الدعم الفني.
- التذكرة تظهر عند الأدمن من جهاز مختلف.
- الطالب والأدمن يقدروا يردوا داخل نفس التذكرة.
- إشعارات المشرف تصل للحسابات على الأجهزة المختلفة عند فتح الموقع.

ملاحظة: الإشعارات هنا إشعارات داخل الموقع، وليست Push Notifications للنظام عندما يكون الموقع مغلقًا.
