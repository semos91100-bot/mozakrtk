الميزة: اختيار الصف والشعبة وقت التسجيل
=======================================

الطالب يختار الصف والشعبة قبل إنشاء الحساب.
الاختيار يُرسل للسيرفر ويتخزن داخل users.state على Supabase:
- grade
- branch
- onboarded=true

بعد الدخول يتم استخدام المسار لتصفية:
- المواد
- المدرسين
- بنك الأسئلة
- الدروس والجدول

المواد التي يوجد لها محتوى تفصيلي في المشروع تعمل بالمحتوى الموجود.
المواد الأخرى تظهر كمادة مستقلة مع تنبيه أن التفاصيل قيد الإضافة، بدل استخدام منهج من شعبة أخرى.
