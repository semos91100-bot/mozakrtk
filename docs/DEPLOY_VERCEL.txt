Vercel deployment checklist

1) Import this project/repository into Vercel.
2) Keep the project root as the folder containing index.html and api/.
3) Add these Environment Variables in Vercel:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
   SESSION_SECRET
   OWNER_EMAIL
   OWNER_PASSWORD
   GEMINI_API_KEY (optional)
   GEMINI_MODEL (optional)

4) Run SUPABASE.sql once in Supabase SQL Editor.
5) Redeploy after saving the environment variables.

Notes:
- The browser never receives SUPABASE_SERVICE_ROLE_KEY.
- OWNER is the only role allowed to assign roles.
- Role assignment is done by student phone number.
- OWNER is the only role allowed to add/change a student's email.
- OWNER can open a support ticket; the backend creates a real OWNER user row so the ticket is visible to all staff and replies/notifications can return to OWNER.

6) مهم: على Vercel لا يوجد fallback مشترك بـLocalStorage؛ الحسابات والتذاكر والإشعارات ولوحة OWNER تعتمد على Supabase حتى تظهر بين الأجهزة.
