نسخة مُذاكرة — كاملة + تحديثات نظام الدعم الفني
================================================

تم دمج تحديثات نسخة الدعم الفني داخل النسخة الكاملة الأصلية بدون حذف وظائف الموقع الأصلية.

الموجود في النسخة:
- كل صفحات ومحتوى النسخة الكاملة الأصلية.
- بنك الأسئلة، الاختبارات، المؤقت، الجدول، المدرسون، الإحصائيات، الإنجازات، الحساب والإعدادات.
- لوحة الإدارة الأصلية لإدارة المدرسين والإشعارات.
- نظام تذاكر دعم فني مُحدث: موضوع، تصنيف، أولوية، حالات، محادثة داخل التذكرة، بحث وفلاتر، وردود الإدارة.
- ترحيل تلقائي لأي تذاكر دعم قديمة محفوظة في localStorage من النسخة السابقة.
- بدون PHP وبدون Runtime خاص بـ PHP، ومناسب لرفع Static على Vercel.
