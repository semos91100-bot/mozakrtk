# مُذاكرة — النسخة الجاهزة للرفع

منصة مذاكرة لتالتة ثانوي علمي علوم، بنفس التصميم الأصلي، مع:

- تسجيل حساب بالبريد الإلكتروني وكلمة مرور.
- حفظ تقدم الطالب على السيرفر واستعادته من أي جهاز.
- مدرس AI مستقل عن claude.ai.
- مدرس AI يعمل عبر Gemini من السيرفر، بحيث لا يظهر مفتاح الـAPI للطلاب.
- حفظ الاختبارات والدرجات والجلسات والـStreak والإعدادات والتقدم ضمن حساب الطالب.
- نسخة محلية من البيانات تعمل كاحتياط داخل المتصفح.

## متطلبات الاستضافة

- Vercel.
- مشروع Supabase لتخزين بيانات الحسابات والمحتوى.
- متغيرات البيئة الموضحة في `SETUP.txt`.
- `GEMINI_API_KEY` اختياري لو عايز مدرس AI.

## تشغيل سريع

1. ارفع المشروع إلى GitHub ثم اعمل Import في Vercel.
2. أنشئ مشروع Supabase وشغّل `supabase.sql`.
3. أضف متغيرات البيئة الموجودة في `SETUP.txt` داخل Vercel.
4. اعمل Redeploy.

## الأمان

- كلمة مرور المشرف لا توجد كنص صريح داخل الواجهة؛ يتم التحقق من هاش موجود في Environment Variables.
- جلسة الدخول عبارة عن Cookie موقعة بـ HttpOnly وSecure وSameSite=Lax.
- مفتاح Gemini يبقى على السيرفر ولا يظهر في JavaScript.
- بيانات الطلاب والمحتوى والإشعارات والدعم محفوظة في Supabase بدل ملفات JSON، لأن ملفات Vercel ليست قاعدة بيانات دائمة.

## الملفات

- `index.html` — واجهة الموقع.
- `assets/` — التصميم والمنهج والوظائف الأمامية.
- `api/api.js` — Vercel Function للتسجيل والدخول والحفظ ومدرس AI ولوحة التحكم.
- `supabase.sql` — جدول قاعدة البيانات.
- `.env.example` — أسماء متغيرات البيئة المطلوبة.

## المدرسون

بيانات المدرسين وروابطهم داخل `TEACHERS` في `assets/data.js`. لإضافة رابط لمدرس ضيف سطر `_lk("نوع","الاسم","الرابط")` داخل `links` الخاصة به. الأنواع: `site` `yt` `fb` `tg` `ig` `app` `lt` `wa`.

## لوحة التحكم (للمشرف)
- سجّل حساب عادي بإيميلك، وضيف نفس الإيميل في `admin_emails` داخل `api/config.php`.
- بعد كده هتلاقي رابط «لوحة التحكم» ظاهر في القائمة الجانبية تلقائيًا.
- من فيها: تعديل/حذف/إضافة مدرّسين (بتظهر لكل الطلاب فورًا)، إرسال إشعار لكل الطلاب أو لإيميل واحد، والرد على رسائل الدعم الفني.

## الدعم الفني والإشعارات
- أي طالب يقدر يبعت رسالة من صفحة «الدعم الفني»، وردّ المشرف بيوصله كإشعار في الجرس 🔔.
- الإشعارات وتذاكر الدعم متخزّنة في `api/storage` زي بيانات الحسابات، بدون أي خدمة سحابية خارجية.
