# مُذاكرة — نسخة Vercel الجاهزة

هذه النسخة تحافظ على واجهة الموقع ومحتواه وصفحاته الأصلية، لكنها لا تعتمد على PHP أو ملفات قابلة للكتابة على السيرفر.

## تشغيل على Vercel

1. ارفع محتويات المجلد إلى GitHub.
2. اربط المستودع بـ Vercel.
3. لا تحتاج Build Command أو Environment Variables لتشغيل الموقع الأساسي.
4. Vercel سيقدّم `index.html` كموقع Static مباشر.

## مدرس AI

واجهة مدرس AI موجودة كما في النسخة الأصلية، لكن تشغيل الذكاء الاصطناعي يحتاج مزود AI ومفتاح API. النسخة المستقلة لا تضع مفتاحًا سريًا داخل JavaScript.

## الملفات

- `index.html` — الواجهة الأصلية.
- `assets/data.js` — المنهج والمحتوى والأسئلة والمدرسون.
- `assets/styles.css` — التصميم.
- `assets/views.js` — صفحات الموقع.
- `assets/app.js` — الاختبارات والمؤقت والأحداث.
- `assets/core.js` — الحالة والحساب والمزامنة المحلية.
- `assets/local-api.js` — طبقة حسابات/دعم/إشعارات محلية متوافقة مع الواجهة الأصلية.
- `legacy_php_backup/` — نسخة احتياطية من ملفات PHP القديمة، ليست جزءًا من تشغيل Vercel.
