نسخة مذاكرتك — كاملة + دعم فني وإشعارات مشتركة
================================================

النسخة مبنية على الموقع الكامل الأصلي، مع نظام تذاكر الدعم الفني، وإشعارات مشتركة بين الأجهزة عبر Vercel API + Supabase.

الموجود:
- كل صفحات ومحتوى الموقع الأصلي.
- بنك الأسئلة والاختبارات والمؤقت والجدول والمدرسين والإحصائيات والإنجازات والحساب والإعدادات.
- لوحة الإدارة وإدارة المدرسين والإشعارات.
- تذاكر دعم للطلاب: فتح تذكرة، ردود، أولوية، حالة وتصنيفات.
- ظهور تذكرة الطالب عند الأدمن حتى لو كان الطالب على جهاز مختلف.
- رد الأدمن يصل للطالب داخل التذكرة والإشعارات.
- لا يوجد PHP.

للتشغيل المشترك:
1. شغّل SUPABASE.sql في Supabase SQL Editor.
2. أضف متغيرات البيئة الموجودة في .env.example داخل Vercel.
3. اعمل Redeploy.
