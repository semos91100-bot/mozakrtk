# مُذاكرة — Vercel Complete (نظام دعم فني احترافي + هوية ألوان جديدة)

نسخة Vercel كاملة للموقع، بدون PHP وبدون قاعدة بيانات — كله يعمل بـ HTML/CSS/JS ساكن + localStorage.

## الجديد في هذه النسخة
- **نظام تذاكر دعم فني احترافي (Support Ticket System)**:
  - الطالب يفتح تذكرة بموضوع + تصنيف (تقني/تعليمي/دفع/حساب/اقتراح/أخرى) + أولوية (منخفضة/متوسطة/عالية/عاجلة).
  - محادثة ثريد كاملة بين الطالب وفريق الدعم مع وقت كل رسالة.
  - حالات التذكرة: مفتوحة → قيد المعالجة → تم الحل → مغلقة.
  - لوحة أدمن مخصّصة: كل التذاكر، فلترة بالحالة/الأولوية/بحث بالاسم، إحصائيات سريعة (مفتوحة، قيد المعالجة، محلولة، عاجلة).
  - إشعارات تلقائية للطرفين عند أي رد جديد.
- **هوية ألوان احترافية جديدة**: أزرق ملكي (Primary) + لمسة ذهبية (Accent) + درجات رمادية محايدة، مع دعم كامل للوضع الليلي.

## النشر
ارفع الملفات كما هي إلى GitHub ثم استورد المستودع إلى Vercel واضغط Deploy. لا يوجد Build Command ولا PHP.

## التخزين
كل البيانات (حسابات، تذاكر الدعم، إشعارات، تقدم) محفوظة في localStorage بالمتصفح — بدون سيرفر. للمزامنة الحقيقية بين الأجهزة لازم قاعدة بيانات خارجية لاحقًا.

## بنية الملفات
```
index.html
assets/
  styles.css      ← الألوان والتصميم
  data.js         ← المواد، المدرّسين، تصنيفات/أولويات التذاكر
  local-api.js    ← localStorage: حسابات + تذاكر دعم + إشعارات
  core.js         ← راوتر، ثيم، مودالز، مؤقت مذاكرة
  views.js        ← كل صفحات الموقع، وأهمها صفحة الدعم الفني
  app.js          ← ربط القوائم والراوتات
```
